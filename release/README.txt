EveJS Character Transfer v0.2.0

1. Extract the whole EveJS-Character-Transfer-v0.2.0 folder somewhere writable.
2. Run EveJS-Character-Transfer.exe from that extracted folder.

Operational data, temporary runs, logs, history, and recovery backups are stored
under .\data next to the EXE. Prepare backups may be large. Completed backups
remain until you explicitly remove them in the application.

Do not run the utility directly from a protected or unwritable directory. If the
data directory cannot be written, the application will stop before an operation
can begin and ask you to move/extract the whole folder to a writable location.
